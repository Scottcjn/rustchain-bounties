# Grant Proposals

Collecting proposals for RustChain Micro-Grants.

## How to Submit

Comment on the [grant issue](https://github.com/Scottcjn/rustchain-bounties/issues/402) with a 1-page proposal using the template below:

```
## Grant Proposal

**Title**: Your project name
**Tier**: Builder / Researcher / Pioneer
**What**: What you want to build (2-3 sentences)
**Why**: Why it matters for RustChain (2-3 sentences)
**How**: Your approach and tech stack
**Timeline**: Expected completion (2-8 weeks)
**Deliverable**: What you'll deliver (code, paper, demo, etc.)
**RTC Wallet**: your-wallet-name
```
