# Why I Chose Elyan Labs Repos

I chose to work on an Elyan Labs repo because the bounty system offered a clear, structured way to contribute meaningful work while learning the codebase. The vintage-hardware angle immediately stood out as a unique niche that few other projects explore, making it both intellectually interesting and technically rewarding. What nearly made me leave was the initial unfamiliarity with the RustChain architecture, but once I dug in, the code quality and documentation made it straightforward to find a valuable contribution. One thing that would have made me do more is if there were more beginner-friendly "good first issue" labels to help newcomers identify high-impact entry points faster.
