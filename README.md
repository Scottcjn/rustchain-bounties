# RustChain Micro-Grants

**Not a bounty — a grant.** Bounties solve OUR problems. Grants fund YOUR ideas.

Propose a project that uses, extends, or promotes RustChain. If approved, you get funding to build it.

---

## Grant Tiers

| Tier | Amount | Scope |
|------|--------|-------|
| **Builder** | 100 RTC | Tool, integration, or app using RustChain |
| **Researcher** | 150 RTC | Paper or analysis of RustChain consensus/tokenomics/security |
| **Pioneer** | 200 RTC | Port the miner to a new architecture (RISC-V, MIPS, s390x, etc.) |

## How to Apply

Comment on the grant issue with a 1-page proposal:

```
## Grant Proposal

**Title**: Your project name
**Tier**: Builder / Researcher / Pioneer
**What**: What you want to build (2-3 sentences)
**Why**: Why it matters for RustChain (2-3 sentences)
**How**: Your approach and tech stack
**Timeline**: Expected completion (2-8 weeks)
**Deliverable**: What you'll deliver (code, paper, demo, etc.)
**RTC Wallet**: your-wallet-name
```

## Review Process

- Proposals reviewed within 1 week
- Community can comment and vote (thumbs up/down)
- Maintainers make final decision
- 50% paid upfront, 50% on completion

## What We're Excited About

- RustChain block explorer improvements
- Mobile wallet app
- Miner dashboard / monitoring tool
- RustChain SDKs in new languages (Rust, Go, JavaScript)
- Academic analysis of Proof-of-Antiquity consensus
- Miner ports to exotic hardware (SPARC, MIPS, Haiku OS, etc.)
- RTC payment integrations for existing apps
- Educational content series

## What We Won't Fund

- Vaporware proposals with no clear deliverable
- Projects that require us to change our core consensus
- "I'll build a DEX" with no exchange development experience
- Anything that already exists and just needs to be forked
