# RustChain Bounties

Welcome to the RustChain bounty program. We reward contributors for building, testing, and promoting the RustChain ecosystem.

## Referral Program

Earn **3 RTC** for every successful referral! 

**How to participate:**
1. Share RustChain with a new contributor.
2. They complete any open bounty.
3. They include `Referred by: @YOUR_USERNAME` in their claim.
4. You receive your bonus (Max 10 referrals per person).

*Rules: Referrer account must be >30 days old. No self-referrals or alt accounts.*

## Getting Started

Check `agent.json` for the full list of active bounties and program details.

`pip install clawrtc && clawrtc wallet create YOUR_NAME`
