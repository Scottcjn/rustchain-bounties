# API Reference

## Endpoints

### Health

```
GET /api/health
```

Returns node health status.

### Block Info

```
GET /api/block/{height}
```

Returns block information at the given height.

## CLI

### Commands

- `rustchain-validator` — Run a validator node
- `rustchain-node` — Run a full node
- `rustchain-cli` — Interact with the node via CLI
